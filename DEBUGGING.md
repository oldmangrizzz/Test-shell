# Debugging Guide

This repository is set up to help debug code that will be imported.

## Getting Started

1. **Import your code** - Add your code files to this repository
2. **Identify the issue** - Describe what's going wrong
3. **Review the code** - We'll examine the code together to find the problem

## Debugging Process

### Step 1: Understand the Expected Behavior
- What should the code do?
- What inputs should it accept?
- What outputs should it produce?

### Step 2: Identify the Actual Behavior
- What is the code actually doing?
- Are there error messages?
- What are the symptoms of the problem?

### Step 3: Isolate the Problem
- Where does the code fail?
- Which function or module is problematic?
- Can you reproduce the issue consistently?

### Step 4: Test and Verify
- Create test cases to validate the fix
- Run the code with different inputs
- Verify the solution works as expected

## Common Issues to Check

- [ ] Syntax errors
- [ ] Logic errors
- [ ] Missing dependencies
- [ ] Incorrect variable types
- [ ] Off-by-one errors
- [ ] Null/undefined references
- [ ] Incorrect API usage
- [ ] Environment configuration issues

## Tips

- Add print/log statements to trace execution
- Use a debugger to step through the code
- Check edge cases and boundary conditions
- Review recent changes that might have introduced the bug
- Consult documentation for libraries and frameworks used

## Next Steps

Once you've imported the code, we can:

2. Run it to see the error
3. Identify the root cause
4. Implement a fix
5. Test and verify the solution
